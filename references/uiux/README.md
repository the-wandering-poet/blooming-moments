# UI/UX References

This folder stores permanent copies of visual references used for AI Photographer design decisions.

## Files

- `instagram-template-color-typography-reference.png` - Reference for the current Instagram/editorial UI direction: powder blue blocks, warm paper surfaces, olive CTAs, serif typography, and template-style composition.
- `blooming-welcome-reference.png` - Current welcome-page visual reference: soft powder-blue paper backdrop, connected-sprig Blooming wordmark, ivory bottom sheet, and olive Start button.

## Color Tokens

- Welcome powder blue: `#E4EBF1` / RGB `(228, 235, 241)` sampled as the median clean backdrop color.
- Slightly deeper blue shadow: `#E0E9F0` / RGB `(224, 233, 240)` sampled from the more saturated backdrop area.
- Blooming olive: `#65704C` to `#6B7652` family for logo, CTA, and delicate botanical accents.

For reusable product rules, use `docs/DESIGN_PRINCIPLES.md` as the source of truth.
